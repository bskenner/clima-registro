# Code of Conduct

O clima-registro deve ser um espaço acolhedor, direto e colaborativo.

## Comportamentos esperados

- Tratar outras pessoas com respeito.
- Discordar de ideias sem atacar pessoas.
- Explicar sugestões com clareza e paciência.
- Ajudar iniciantes quando possível.
- Manter discussões focadas no projeto.

## Comportamentos não aceitos

- Assédio, intimidação ou insultos.
- Comentários preconceituosos ou discriminatórios.
- Exposição de dados privados.
- Spam, autopromoção fora de contexto ou conteúdo comercial.
- Pressão para adicionar recursos que fujam do objetivo leve e pessoal do projeto.

## Aplicação

Mantenedores podem editar, fechar ou remover comentários, issues e pull requests que prejudiquem o ambiente do projeto. Casos graves podem levar a bloqueio de participação.

O objetivo é simples: colaborar melhor, com menos atrito.
